# Security Policy

## Supported Versions

Optivor actively supports security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| v0.4.x  | :white_check_mark: |
| v0.3.x  | :x:                |
| < v0.3  | :x:                |

## Reporting a Vulnerability

We take the security of Optivor seriously. If you discover a security vulnerability, please do NOT open a public issue.

Instead, please report security vulnerabilities responsibly by using GitHub Private Vulnerability Reporting or contacting core maintainers:

1. **Contact**: Reach out to core maintainers specified in [`CODEOWNERS`](./CODEOWNERS).
2. **Details to Include**:
   - Description of the vulnerability and potential impact.
   - Proof of concept or detailed reproduction steps.
   - Any suggested remediations if available.

## Vulnerability Handling Process

- **Acknowledgment**: We aim to acknowledge receipt of vulnerability reports within 48 hours.
- **Assessment**: The core maintainers will evaluate the impact and severity of the report.
- **Fix & Patch**: If confirmed, a security patch will be prepared on a private branch and released in a patch version update.
- **Disclosure**: Public disclosure will take place after a patch has been released.
