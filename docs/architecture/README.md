# Architecture Docs

This directory will hold implementation-level architecture notes for
each layer (`runtime.md`, `cli.md`, `deployment.md`) as they are built.

These are living documentation, not decision records — for the
"why," see `../adr/`. For the "how it currently works," these files
will be added once there is real code to document, so they don't
drift out of sync with an implementation that doesn't exist yet.
